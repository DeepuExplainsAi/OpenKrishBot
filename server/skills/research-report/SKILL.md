# Research report
1. Use the plan tool: 3 to 6 steps (questions to answer, sources to read, then write-up).
2. Search the web for each question and open the best 3 to 5 pages; prefer primary sources and pages from the last 12 months for anything that changes.
3. Note the date of each source. When sources disagree, say so; do not average them.
4. Write: a 3-line answer first, then findings in short sections, then a "Sources" list with links. Mark what you could not confirm.
5. For a long report, save it with save_file so the user finds it in the Library.
