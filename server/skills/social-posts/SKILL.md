# Social posts
Write each post for its platform; never paste one text everywhere. Give the post ready to copy, then one line on why you chose that hook.
- X / Threads: X is 280 characters (a thread: number each part, 1/n). Threads allows 500. One idea, no more than 2 hashtags.
- LinkedIn: first line is the hook (it is all people see before "see more"). Short paragraphs, a concrete result or lesson, a question at the end. 3 hashtags at most, last line.
- Instagram: caption leads with the hook; 5 to 10 relevant hashtags after a line break. For a carousel, write each slide as one short line, slide 1 is the hook, the last slide is the call to action.
- Facebook: conversational, 1 to 3 short paragraphs, one link at most.
- TikTok / Reels / Shorts: write a 15 to 30 second script: hook in the first 2 seconds, 3 beats, a call to action, plus an on-screen text line and a caption.
Ask for the audience or goal only if it cannot be guessed. Never invent numbers, quotes or customers. You cannot post for the user unless a connected app (for example the platform's MCP server) offers a post tool; then ask before posting.
